# GENED 1017 — Americans as Occupiers and Nation Builders
## Study Notes

Notes for the course covering American occupation and nation-building across the Philippines, Germany, Japan, and Korea.

---

## Structure

```
notes/
├── week1/–week7/          # One folder per week
│   ├── [reading-slug].md  # One file per assigned reading
│   └── SYNTHESIS.md       # Cross-reading synthesis for the week
├── connection-bank.md     # Cross-reading connections organized by course theme
└── master-glossary.md     # All key terms across all weeks, grouped by theme
```

### Per-reading notes (`[reading-slug].md`)

Each file covers one assigned reading and includes:
- **Summary** — analytical (~500 words for secondary sources, ~200 for short primary sources)
- **Key Quotes** — direct quotes with page numbers and significance
- **Key Terms** — definitions and course relevance
- **Flashcards** — front/back format for review

File names follow the pattern `[author]-[short-title].md` for secondary sources and `[document-name].md` for primary sources.

### Weekly synthesis (`SYNTHESIS.md`)

Pulls together all readings for the week:
- How the readings speak to and complicate each other
- Connections to prior weeks
- Active course themes
- Combined key terms (deduplicated)
- Three-term connection drills with model responses
- Practice essay questions

### Cross-week reference files

| File | Contents |
|------|----------|
| `connection-bank.md` | Cross-reading connections by course theme, keyed to three-term drills |
| `master-glossary.md` | All key terms across all weeks, with cross-references to source readings |
